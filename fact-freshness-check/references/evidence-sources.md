# 证据来源优先级

## 1. 允许作为最终判定的来源

1. **官方当前 GA 版本文档**（注意版本化路径：MySQL `/doc/refman/8.0/`、PostgreSQL `/docs/current/`）。
2. **官方 Release Notes / Changelog / What's New**：判断“哪一版变的”。
3. **官方 issue tracker / 源码 / 官方博客**：文档没写时的补充。

## 2. 只能作为线索，不能单独作为判定

- 知名工程团队博客、会议演讲、技术公众号。
- 使用前必须回溯到上述 1–3 的原始来源。

## 3. 禁止作为最终出处

- 聚合教程站、问答站、旧版镜像、个人笔记。
- 搜索引擎摘要（不是原文）。
- 无法确认版本和日期的页面。

## 4. 判定前必查

| 检查项 | 问题 |
|---|---|
| 版本 | 读的是当前 GA，还是旧版镜像？ |
| 日期 | 页面/Release Notes 的日期是什么？ |
| 产品 | 是同一产品、同一部署形态吗？ |
| 条件 | 结论是否只在特定配置/版本下成立？ |

## 5. 失败处理

- 官方链接失效 → 换 Release Notes/issue；仍失败标 `[未核实]`。
- 来源冲突 → 并列标注，注明日期与版本。
- 无法确认版本 → 先问用户目标版本，不默认最新。
