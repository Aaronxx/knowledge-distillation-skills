# 一页纸排版与结构校验

> 输入是**已定型的内容**（标题、一句话结论、要点、图表、边界、话术都已确定），本 skill 只回答一个问题：**这份内容怎么排进 1–2 页 A4，且打印不溢页、黑白可读、结构自检通过。**

## 解决什么问题

内容定好了却排不出可打印的一页纸：字号乱、标题孤行、表格跨页、图把正文挤出页外、附录页插错位置。本 skill 用固定模板 + 硬约束 + 可执行校验脚本，把"内容"变成"可交付的打印件"，并给出结构层面的失败原因。

不做的事：不压缩、不选点、不判断内容对不对、不核实版本时效——这些是内容侧技能的事。

## 边界清单

| 能做 | 不做 |
|---|---|
| 内容 → 1–2 页 A4 单文件 HTML；页脚、页码、附录页插入 | 删减要点、改结论、决定保留哪些 KU（→ `distill-onepager`） |
| 版式：字号、行高、页边距、分页填充、标题防孤行 | 联网核实版本真伪（→ `fact-freshness-check`） |
| 图示：内联 SVG（流程/层级/状态三类） | 交互页、`<details>`、需 hover 才可见的内容 |
| 结构自检：`scripts/check_onepager.py` | 文案质量、术语准确性、事实断言完整性 |
| 打印实测：Chrome 转 PDF 数页数 | 生成 PDF/DOCX 成品（用户自己打印） |

## 硬约束（排版侧不可越线）

| 项目 | 1 页 | 2 页 | 校验方式 |
|---|---|---|---|
| 每页中文字符 | ≤800（脚本上限 900） | 合计 ≤1600（脚本上限 1700） | `check_onepager.py` |
| 一级标题 | 1 个 | 1 个 | 人工 |
| 图节点数 | ≤8 | ≤12 | 人工 |
| 图 | 0–1 | 1–2 | 脚本计数 |
| 表 | 0–1 | 0–2 | 脚本计数 |
| 最小字号 | 9pt | 9pt | 脚本 |
| 外部依赖 | 0（除系统字体） | 0 | 脚本 |

超过预算时**不许缩小字号或压行距硬塞**——把溢出的小节整体下移或回退给内容侧删减。

## 工作流

1. **接收内容与页数决定**：确认标题、一句话结论（≤40 字）、要点条数、图表数量、易错点、话术是否已定；页数由内容侧或用户给定，本 skill 不自作主张改档位。
2. **复制模板**：`assets/onepager.html` → 目标文件，替换 `{{TITLE}} / {{KICKER}} / {{SOURCE}} / {{DATE}}` 占位。
3. **按页填充**：遵循「分页填充规则」——以段或小节为最小单位，顺序填满一页再填下一页；放不下的整个单位下移，末页允许不满；**禁止为两页满度均衡提前切分小节**。
4. **配图**：按 `references/diagram-playbook.md` 判断关系类型（流程/分支/状态/层级才画图，同维度对比用表格），内联 SVG，不用 Mermaid CDN。
5. **插附录页**：时效区块（≤4 条）放正文页 footer 之前；5–12 条改附录页 `page--freshness`；术语附录 `page--glossary` ≤12 行。三者都不计入知识点页数预算。
6. **自检**：`python scripts/check_onepager.py <file.html>`；`FAIL` 必须修，`WARN` 必须解释或修复。
7. **打印实测**：有 Chrome/Edge 时转 PDF 数页数（`--headless --print-to-pdf`），确认无空白页、无截断、无溢出；无浏览器则注明"未实测页数"。
8. **视觉验收**：模型支持图像输入时，渲染截图逐页过目（见「自检清单」视觉项）；不支持就明确告知用户自行过目，不反复重试读图。

## 分页填充规则（多页文档）

- 最小填充单位 = 一个段或一个小节，**顺序填满一页再填下一页**。
- 下一个单位若放入当前页会溢出（内容进入页脚区或打印升页），该单位**整体**放到下一页开头，当前页保持现状。末页允许不满。
- **禁止为"两页满度均衡"提前切分小节或重新分配内容**——切分点由容量决定，不由对称性决定。
- 满度判定：注入量测 `contentBottom / 1123px`（A4=1123px）或打印页数；**内容底安全上限 ≈1050px**（A4 高 1123 − 底部内边距 17mm≈64px = 1059px，实测触到 1059 即升页，留 8px 余量取 1050）。超出即按单位下移，不得改内边距/行距硬塞。
- 页脚可选：正文已完整落页、仅页脚轻微溢出时**删除页脚**，不升页、不缩字号、不删正文。

## HTML 规范（摘要，全文见 `references/html-spec.md`）

- 单文件 UTF-8、内联 CSS、除系统字体外无外部依赖。
- `@page { size: A4; margin: 0 }`；每个 `.page` 固定 A4，页间 `break-after: page`。
- 正文 10pt / 行高 1.55；最小 9pt；h1 17pt、h2 11.5pt。
- 打印保留背景：`print-color-adjust: exact`。
- 卡片、图、表加 `break-inside: avoid`；标题加 `break-after: avoid` 防孤行。
- 禁用：`position: fixed`、`vh`、`<details>`、hover 才可见的内容。
- 屏幕预览灰底页影，`@media print` 去掉；页脚用静态文本，不用 JS。

## 图示

只画三类关系：**流程/时序**、**分支/状态**、**层级/结构**。三者都不占的用表格，不要硬画。

- 图必须承载信息；删掉图后信息没损失就删图。
- 一张图一个关系；节点 ≤8（1 页）/ ≤12（2 页）。
- 内联 SVG，`viewBox` + `width:100%`；节点文字 ≥9pt（viewBox 680 宽时 `font-size` 13–14）。
- 颜色只做强调，不承载分类；黑白打印后靠文字、箭头、线型仍可读懂。
- 骨架模板与 SVG 约定见 `references/diagram-playbook.md`。

## 自检清单

结构项（`check_onepager.py` 覆盖）：

- [ ] `.page` 数量 = 用户/内容侧决定的 1 或 2；无空白页。
- [ ] 每页中文字符在预算内；时效/术语附录页按豁免单独统计。
- [ ] 最小字号 ≥9pt；外部依赖 0。
- [ ] 图数、表数在档位上限内。
- [ ] 两级标题无撞词（脚本 `WARN` 必须解释或修复）。

人工项：

- [ ] 无标题孤行（标题后至少跟一行正文）。
- [ ] 表格、图、卡片未跨页断裂。
- [ ] 时效区块在 footer 之前且 `break-inside: avoid`；≤4 条为区块、5–12 条为附录页。
- [ ] 术语附录页只收正文出现过的缩写、≤12 行、按首次出现顺序。
- [ ] 页脚：来源与页码是静态文本；若仅页脚溢出，已删除页脚并记录。
- [ ] 浏览器 Ctrl+P 预览：无内容溢出到页脚区、无截断。
- [ ] 视觉验收：模型支持图像输入时已渲染过目；不支持时已告知用户自行过目。

## 异常与兜底

| 场景 | 处理 |
|---|---|
| check `FAIL` | 按报告删卡/合并要点后重跑；仍溢出则升页（1→2）或减图，禁止缩字号 |
| 仅页脚轻微溢出 | 删页脚，不升页、不缩字号；报告注明"页脚省略" |
| 内容明显超 2 页 | 不硬排，退回内容侧（`distill-onepager`）重新选点，或与用户确认改 `docs-to-knowledge` |
| 用户要求 3 页以上 | 停手并说明本 skill 不做，转 `docs-to-knowledge` |
| 图节点超上限 | 拆图、改表格或删图；不缩字号 |
| 无浏览器 | 跳过打印实测，结构自检照常执行 |
| 模板被改坏 | 从 `assets/onepager.html` 重新复制，不要手工救 |

## 状态与权限

- 多轮状态：`.skill-state/<中文任务名>.md`，字段：内容来源 / 页数档位 / 已填小节 / check 结果 / 实测页数 / 待修项。
- 高风险操作需二次确认：覆盖已有 HTML、删除用户文件、写到用户指定目录之外。
- 不修改内容语义；发现问题只回报，不擅自改写结论。

## 反模式

| 不要 | 要 |
|---|---|
| 缩小字号、压行距把内容硬塞进 1 页 | 按填充规则下移或回退内容侧删减 |
| 为"两页长得均衡"提前切小节 | 顺序填满一页，溢出单位整体下移，末页允许不满 |
| 所有知识都画图 | 只有流程、分支、层级才画 |
| 依赖 Mermaid CDN | 内联 SVG |
| 把内容折叠进 `<details>` | 打印会丢，直接删或改表 |
| 排版时顺手改结论、删要点 | 内容问题回报给内容侧，不擅自改 |
| 只跑 check 不做打印实测 | 结构自检 + 实测页数双确认（无浏览器时注明） |
