# 一页纸排版与结构校验

> 输入是**已定型的内容**（标题、一句话结论、要点、图表、图片清单、边界、话术都已确定），本 skill 只回答一个问题：**这份内容怎么排进 1–3 页 A4，且打印不溢页、黑白可读、结构自检通过。**

## 解决什么问题

内容定好了却排不出可打印的一页纸：字号乱、标题孤行、表格跨页、图把正文挤出页外、原图内嵌后文件过大、附录页插错位置。本 skill 用固定模板 + 硬约束 + 可执行校验脚本，把"内容"变成"可交付的打印件"，并给出结构层面的失败原因。

不做的事：不压缩、不选点、不判断内容对不对、不决定哪张图该留（图片去留由内容侧提前定好）、不核实版本时效。

## 边界清单

| 能做 | 不做 |
|---|---|
| 内容 → 1–3 页 A4 单文件 HTML；页脚、页码、附录页插入 | 删减要点、改结论、决定知识点去留（→ `distill-onepager`） |
| 版式：字号、行高、页边距、分页填充、标题防孤行 | 联网核实版本真伪（→ `fact-freshness-check`） |
| 图示：内联 SVG（流程/层级/状态三类） | 判断"这张图该不该留"（内容侧已定） |
| 原图内嵌：base64、尺寸上限、灰度可读性、图注版式 | 修图/重绘截图（重绘属内容侧） |
| 结构自检：`scripts/check_onepager.py` | 文案质量、术语准确性、事实断言完整性 |
| 打印实测：Chrome 转 PDF 数页数 | 生成 PDF/DOCX 成品（用户自己打印） |

## 硬约束（排版侧不可越线）

| 项目 | 1 页 | 2 页 | 3 页 | 校验方式 |
|---|---|---|---|---|
| 每页中文字符 | ≤800（脚本上限 900） | 合计 ≤1600（上限 1700） | 合计 ≤2400（上限 2600） | `check_onepager.py` |
| 一级标题 | 1 个 | 1 个 | 1 个 | 人工 |
| 图节点数 | ≤8 | ≤12 | ≤12 | 人工 |
| 图（SVG＋内嵌原图） | 0–1 | 1–2 | 2–4 | 脚本计数 |
| 表 | 0–1 | 0–2 | 0–3 | 脚本计数 |
| 内嵌图体积 | 单图 ≤400KB，总计 ≤2MB | 同左 | 同左 | 脚本 |
| 最小字号 | 9pt | 9pt | 9pt | 脚本 |
| 外部依赖 | 0（除系统字体） | 0 | 0 | 脚本 |

超过预算时**不许缩小字号或压行距硬塞**——把溢出的小节整体下移，或回退给内容侧删减/决定是否升页。**3 页只在内容侧给出突破理由后才排**；本 skill 不自行决定升页。

## 工作流

1. **接收内容与页数决定**：确认标题、一句话结论（≤40 字）、要点条数、图表数量、**图片清单（含图注与原始图片文件）**、易错点、话术是否已定；页数（1/2/3）由内容侧或用户给定，本 skill 不自作主张改档位。
2. **复制模板**：`assets/onepager.html` → 目标文件，替换 `{{TITLE}} / {{KICKER}} / {{SOURCE}} / {{DATE}}` 占位。
3. **按页填充**：遵循「分页填充规则」——以段或小节为最小单位，顺序填满一页再填下一页；放不下的整个单位下移，末页允许不满；**禁止为两页满度均衡提前切分小节**。
4. **配图**：自绘内联 SVG 按 `references/diagram-playbook.md` 判断关系类型（流程/分支/状态/层级才画图，同维度对比用表格）；原图按「图片版式规范」转 base64 内嵌。不用 Mermaid CDN，不用外链图片。
5. **插附录页**：时效区块（≤4 条）放正文页 footer 之前；5–12 条改附录页 `page--freshness`；术语附录 `page--glossary` ≤12 行。三者都不计入知识点页数预算。
6. **自检**：`python scripts/check_onepager.py <file.html>`；`FAIL` 必须修，`WARN` 必须解释或修复。
7. **打印实测**：有 Chrome/Edge 时转 PDF 数页数（`--headless --print-to-pdf`），确认无空白页、无截断、无溢出；无浏览器则注明"未实测页数"。
8. **视觉验收**：模型支持图像输入时，渲染截图逐页过目（见「自检清单」视觉项）；不支持就明确告知用户自行过目，不反复重试读图。

## 分页填充规则（多页文档）

总原则：**分页点由容量贪心决定，不由主题、视觉对称或"章节归属"决定**。按顺序把一个单位一个单位往当前页装，装不下才换页；任何"为了某一页看起来正好收尾"而提前换页，都算违规。

### 1. 填充单位与贪心算法

- 最小填充单位 = **一个 h2 小节（h2 + 其下全部内容块，直到下一个 h2 之前）**；h2 与其首块不得被拆到两页。
- 从第 1 页开始按文档顺序累加单位：`try = 当前页 contentBottom + 该单位高度`；
  - `try ≤ 内容上限（1050px）` → 装入本页，继续下一个单位；
  - `try > 上限` → **整个单位移到下一页开头**，本页封版（不得拆开该单位、不得缩字号/行距硬塞）。
- 末页允许不满；附录页（时效/术语）独立成页，不计入知识点页数，也不参与上述贪心。

### 2. 非末页填充率门槛（新增，强制）

- 除最后一页知识点页外，**每一页的 `contentBottom` 必须 ≥ 900px（≈86% 上限）**。
- 若不达标：优先把下一页开头的第一个单位整体上提（哪怕它使本页接近 1050）；上提后仍不达标，说明页面切分是"按主题切"而非"按容量切"，必须重新组织，而不是留白交付。
- 反例（真实踩坑）：第 1 页内容底仅 631px（56%），第 2 页开头却是一张 250px 高的机制图——典型"按章节切页"。正确做法是把该图与后续小节上提，直到装不下为止。

### 3. 必须实测，不许目测

1. 注入量测脚本（`<script>` 计算每个 `.page` 内除 `.footer` 外子元素的 `bottom`，把结果写入 `#MEASURE` 的 `<pre>`）。
2. 无 Python 环境下用 Chrome 无头取量测结果：
   `chrome --headless=new --virtual-time-budget=4000 --dump-dom "file:///<temp.html>"`，从 DOM 里读 `MEASURE::` 行。
3. 逐页核对：`contentBottom ≤ 1050`；非末页 `≥ 900`；页脚区（约 1067px 起）无内容重叠。
4. 打印实测页数（`--print-to-pdf`）必须与 `.page` 节数一致；多一页即为溢出，少一页即为空页。
5. 交付报告必须给出每页 `contentBottom` 与填充率，未实测需注明原因；"看着还挺满"不算证据。

## HTML 规范（摘要，全文见 `references/html-spec.md`）

- 单文件 UTF-8、内联 CSS、除系统字体外无外部依赖。
- `@page { size: A4; margin: 0 }`；每个 `.page` 固定 A4，页间 `break-after: page`。
- 正文 10pt / 行高 1.55；最小 9pt；h1 17pt、h2 11.5pt。
- 打印保留背景：`print-color-adjust: exact`。
- 卡片、图、表加 `break-inside: avoid`；标题加 `break-after: avoid` 防孤行。
- 禁用：`position: fixed`、`vh`、`<details>`、hover 才可见的内容。
- 屏幕预览灰底页影，`@media print` 去掉；页脚用静态文本，不用 JS。

## 原图内嵌呈现规则

图片去留由内容侧决定，本 skill 只负责**排得进去、打出来能看清、离线不丢图**。

| 规则 | 要求 |
|---|---|
| 内嵌方式 | `<img src="data:image/png;base64,…" alt="…">`，禁止外链（离线打印会白） |
| 体积 | 单图 ≤400KB、总计 ≤2MB；超出由内容侧降采样或裁切，不靠 CSS 缩小掩盖 |
| 尺寸 | `max-width:100%` + `max-height:70mm`（1–2 页档）/ `85mm`（3 页档）；`height:auto` |
| 防断裂 | `<figure>` 与图注一起 `break-inside: avoid`，图不与图注分离 |
| 图注 | 跟在图下方，9pt、灰色；写"这张图回答什么问题"，不写"图 1" |
| 灰度可读 | 彩色标注必须配文字说明；缩到 80% 预览仍能分辨层级 |
| 与 SVG 混排 | 同一页内 SVG 与内嵌图合计不超过档位上限；两者都不承载信息的图删掉 |
| 文件体积 | 整份 HTML ≤3MB；超出说明有图未压缩，回内容侧处理 |

## 图示

只画三类关系：**流程/时序**、**分支/状态**、**层级/结构**。三者都不占的用表格，不要硬画。

- 图必须承载信息；删掉图后信息没损失就删图。
- 一张图一个关系；节点 ≤8（1 页）/ ≤12（2 页）。
- 内联 SVG，`viewBox` + `width:100%`；节点文字 ≥9pt（viewBox 680 宽时 `font-size` 13–14）。
- 颜色只做强调，不承载分类；黑白打印后靠文字、箭头、线型仍可读懂。
- 骨架模板与 SVG 约定见 `references/diagram-playbook.md`。

## 自检清单

结构项（`check_onepager.py` 覆盖）：

- [ ] `.page` 数量 = 用户/内容侧决定的 1 或 2；无空白页。
- [ ] 每页中文字符在预算内；时效/术语附录页按豁免单独统计。
- [ ] 最小字号 ≥9pt；外部依赖 0。
- [ ] 图数、表数在档位上限内。
- [ ] 两级标题无撞词（脚本 `WARN` 必须解释或修复）。

人工项：

- [ ] 无标题孤行（标题后至少跟一行正文）。
- [ ] 表格、图、卡片未跨页断裂。
- [ ] 分页点由容量贪心决定：每页按单位顺序装填，未出现"按章节切页"导致的半页空白；非末页 `contentBottom ≥ 900px`。
- [ ] 每页 `contentBottom ≤ 1050px`，页脚区（约 1067px 起）无内容重叠；打印页数 = `.page` 节数。
- [ ] 内嵌图有 alt 与图注；`<figure>` 与图注未被分页拆开；单图 ≤400KB、总计 ≤2MB、整份 HTML ≤3MB。
- [ ] 3 页档：内容侧已给出突破理由（本 skill 不自行升页）。
- [ ] 时效区块在 footer 之前且 `break-inside: avoid`；≤4 条为区块、5–12 条为附录页。
- [ ] 术语附录页只收正文出现过的缩写、≤12 行、按首次出现顺序。
- [ ] 页脚：来源与页码是静态文本；若仅页脚溢出，已删除页脚并记录。
- [ ] 浏览器 Ctrl+P 预览：无内容溢出到页脚区、无截断。
- [ ] 视觉验收：模型支持图像输入时已渲染过目；不支持时已告知用户自行过目。

## 异常与兜底

| 场景 | 处理 |
|---|---|
| check `FAIL` | 按报告删卡/合并要点后重跑；仍溢出则升页（1→2）或减图，禁止缩字号 |
| 仅页脚轻微溢出 | 删页脚，不升页、不缩字号；报告注明"页脚省略" |
| 内容明显超 2 页 | 不硬排，退回内容侧（`distill-onepager`）重新选点，或与用户确认改 `docs-to-knowledge` |
| 用户要求 3 页以上 | 停手并说明本 skill 不做，转 `docs-to-knowledge` |
| 图节点超上限 | 拆图、改表格或删图；不缩字号 |
| 内嵌图体积超限 | 回内容侧降采样/裁切；不在 CSS 里缩小假装合规 |
| 图片损坏或格式不支持 | 转 PNG/JPEG 后重试；仍失败则删除并告知，不显示破图 |
| 3 页仍装不下 | 回内容侧删减或转 `docs-to-knowledge`；本 skill 不做 4 页 |
| 无浏览器 | 跳过打印实测，结构自检照常执行 |
| 模板被改坏 | 从 `assets/onepager.html` 重新复制，不要手工救 |

| 不要 | 要 |
